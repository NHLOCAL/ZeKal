# זה קל! | NH LOCAL

[זה קל!](https://ze-kal.top/) הוא מותג העל ושער הכניסה לפרויקטים של NH LOCAL: אתרים, תוכנות, כלי AI, מוזיקה ומדריכים בעברית.

האתר נבנה ב-Jekyll ומתפרסם דרך GitHub Pages מתוך תיקיית `docs` בענף `main`. הקטלוג וכל הקישורים נכתבים ל-HTML בזמן הבנייה. JavaScript מוסיף חיפוש, סינון, מצב כהה ותפריט מותאם לנייד.

## הפעלה מקומית

נדרשים Ruby, Bundler והתלויות המוגדרות ב-`docs/Gemfile`.

```powershell
cd docs
bundle install
bundle exec jekyll serve --host 127.0.0.1
```

פותחים את [התצוגה המקומית](http://127.0.0.1:4000/). הגופן והלוגואים נטענים מהאתר עצמו. עמוד הסרטונים הוותיק משתמש גם ב-Font Awesome.

## תוכן ותחזוקה

- `docs/_data/projects.yml`: מקור האמת לקטלוג, כולל תיאור, כתובת, פלטפורמה, קטגוריות ומילות חיפוש. `featured: true` מציג פרויקט גם בחלק הנבחרים. לכל יעד נשמר `source` לצורך אימות.
- `docs/_data/categories.yml`: ארבעה תחומי שימוש. המדריכים הייחודיים נמצאים ב-`docs/projects/`.
- `docs/learn/index.html`: שער התוכן הלימודי. כתובות `/topics/*.html` ו-`/youtube-channel.html` נשמרות באמצעות permalinks מפורשים.
- `docs/assets/css/gateway.css`: עיצוב רספונסיבי, RTL, משתני צבע ומצב כהה.
- `docs/assets/js/catalog.js`: חיפוש מקומי, מילים חלופיות, סינון והרחבת הקטלוג. החיפוש והקטגוריה נשמרים בכתובת לצורך שיתוף; ה-canonical נשאר נקי מפרמטרים.
- `docs/assets/js/gateway.js`: תפריט, ערכת נושא והקראת מילים באנגלית.
- `docs/_includes/project-schema.html`: נתוני WebSite, ItemList ו-BreadcrumbList בהתאם לעמוד.

פרויקט נוסף צריך לקבל מזהה ייחודי, תיאור שימושי וכתובת אמינה. אין להציג נתוני מחיר או טענות על זמינות שלא נבדקו. פרויקטים ותיקים יכולים לקבל שדה `status`. סוגי השדות והערכים מודגמים בקטלוג הקיים.

זה קל! הוא שם האתר והמותג הראשי. NH LOCAL הוא חתימת היוצר. שמות המוצרים והלוגואים שלהם נשמרים בתוך המשפחה.

## בדיקות לפני פרסום

```powershell
cd docs
bundle exec jekyll build
cd ..
node scripts/check-site.mjs
node --check docs/assets/js/catalog.js
node --check docs/assets/js/gateway.js
git diff --check
```

בדיקת האתר אינה דורשת חבילות Node נוספות. היא מאמתת עמודים נדרשים, H1, כותרות ותיאורים, canonical, JSON-LD, קישורים פנימיים, תמונות שיתוף, מזהים, robots ו-sitemap.

יש לבדוק גם בדפדפן: חיפוש בעברית ובאנגלית, סינון משולב, אפס תוצאות, הרחבה, חזרה, קישור עם פרמטרים, מצב כהה, תפריט במקלדת ותצוגה צרה. התוכן זמין גם כשה-JavaScript כבוי.

טופס המשוב משתמש בכתובת Formspree הקיימת. בדיקות מקומיות לא אמורות לשלוח הודעות אמיתיות. האתר לא מוסיף כלי מעקב או פרמטרי UTM לקישורי הפרויקטים.

## פרסום

GitHub Pages מפרסם את `main:/docs`. עבודה בענף פיתוח וקומיטים מקומיים אינם פריסה. לפני מיזוג יש להשלים את הבדיקות; אחרי הפריסה יש לוודא את האתר הציבורי, המפה ותצוגת השיתוף.
