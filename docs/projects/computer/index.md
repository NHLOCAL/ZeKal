## לסדר את הקבצים שחוזרים ומצטברים

אם תיקיית ההורדות מתמלאת בקבצים מסוגים שונים, [מסדר ההורדות](https://github.com/NHLOCAL/File-Sorter) נועד למיין אותם לפי סוג. כשצריך ליצור גיבוי מראה בין תיקיות, אפשר לבדוק את [מסייע הגיבוי](https://github.com/NHLOCAL/backup-assistant). אלה שתי משימות שונות, ולכן כדאי לבחור לפי התוצאה הרצויה: תיקייה מסודרת או עותק גיבוי.

## לפתוח כלי ולבצע פעולה בדפדפן

ב[ארגז הכלים](https://tools.ze-kal.top/) מרוכזים כלים שאפשר לפתוח בדפדפן לצד סקריפטים ותוספים להורדה. למשל, [עורך HTML חי](https://tools.ze-kal.top/tools/html_editor.html) מתאים לכתיבת קוד ולבדיקת התוצאה בתצוגה מקדימה. זה מסלול שימושי כשרוצים לבצע פעולה ממוקדת ולראות מיד את התוצאה.

## לבחור גם את צורת העבודה

כלי דפדפן מתאים לעבודה מתוך האתר, תוכנה מותקנת מתאימה לשימוש על המכשיר, וסקריפט יכול להשתלב בפעולות חוזרות. בכל פרויקט כדאי לפתוח את דף ההסבר או המקור כדי למצוא את הוראות ההפעלה. [מדריך ההורדה של ארגז הכלים](https://tools.ze-kal.top/downloads.html) מרכז את הדרכים לשמור ולהפעיל את הכלים שמופיעים בו.
